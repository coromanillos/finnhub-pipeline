# finnhub-pipeline
Batch processing data pipeline using Airflow, S3, dbt, and snowflake  

Goal: "This data identifies correlations between lobbying activity, government contract awards, and earnings performance across 60 public companies in defense, energy, and tech."

Result: "The lobbying to contract relationship is most likely sector dependent, and not a simple correlation across all 60 companies. i.e. if two companies from different sectors were to equally invest in lobbying for contracts, there is no guarantee of similar return unless they are from the same sector"?*
